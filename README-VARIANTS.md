## 怎么看、怎么选

GitHub 只把根目录下的 `README.md` 渲染为仓库首页；这三个候选是普通 Markdown 文件，**点开即为完整渲染效果**（与它成为 `README.md` 时一致，因为都在根目录，`docs/...` 相对图片路径不受影响）。

- 想看「作为仓库首页」的真实观感：可以为每版各建一个分支，切分支即可对比；也可以让我把任一版覆盖到 `README.md`，一次 commit 完成、随时可回退。
- 确定采用哪一版后告诉我编号，我会把它提升为 `README.md`，并删除其余候选与本索引。
- 三版都不满意也没关系：删除这几个文件即可，现状不受影响。
